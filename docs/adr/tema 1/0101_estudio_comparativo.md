Las tres tecnologias a cubrir en este estudio comparativo son Android nativo, Flutter y PWA

Lenguaje y herramientas necesarias

- Android native: El lenguaje que usa es Kotlin y la herramienta necesaria para usar esta tecnología
es Android Studio
- Flutter: El lenguaje que usa es Dart y la herramienta necesaria para usar esta tecnología es 
Flutter SDK junto con un IDE
- PWA: El lenguaje que usa es JavaScript/TypeScript, y las herramientas necesarias para usar esta 
tecnología son un service worker y un manifiesto como mínimo

Plataformas que soporta

- Android native: Solo android
- Flutter: Multiplataforma 
- PWA: Multiplataforma

Rendimiento y acceso al hardware

- Android native: Rendimiento máximo y acceso total al hardware en dispositivos android
- Flutter: Buen rendimiento pero no iguala a un lenguaje nativo de android, acceso al hardware 
limitado por el framework ya que las novedades tienen que ser implementadas y los desarrolladores 
del framework tienen que decidir como exponerlas
- PWA: Rendimiento medio/bajo, acceso al hardware limitado por razones de seguridad y arquitectura
del navegador

Coste de desarrollo y mantenimiento

- Android native: Coste alto si se quieren cubrir mas plataformas que android, mantenimiento 
caro si se ha desarrollado para más plataformas 
- Flutter: Coste entre un 50-70% más barato de desarrollo y de mantenimiento ya que el código 
funciona para android e iOS 
- PWA: Coste muy bajo de desarrollo y mantenimiento ya que se puede reutilizar mucho código

Caso de uso real en la que cada tecnología sea la mejor opción:

- Android native: Para un juego 3D, que exige alto rendimiento, ya que ofrece la forma más optima 
de utilizar el hardware y la que ofrece mayor rendimiento entre las 3 tecnologías, además de que
ofrece la mayor compatibilidad con los sensores del dispositivo y optimización
- Flutter: Para una app que no requiera el máximo rendimiento y que tenga un presupuesto limitado de
desarrollo, ya que ofrece un buen rendimiento y además ofrece soporte multiplataforma, por lo que el 
desarrollo sería mucho más barato
- PWA: Un prototipo que se quiere validar rápido y con un ciclo de vida previsiblemente corto, ya
que el desarrollo será mas corto y además no hacen falta conocimientos especificos para aplicaciones
móviles
