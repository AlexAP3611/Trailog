Conclusiones

- Debido a la capacidad de almacenamiento del dispositivo, la aplicación puede guardar localmente 
información de las rutas, como mapas, recorridos y datos de actividades anteriores. Esto permitirá
que el usuario pueda conservar sus rutas y descargar previamente los recursos necesarios para 
utilizarlos durante una excursión
- El dispositivo dispone de un giroscopio, sensor de campo magnético y diferentes 
sensores de orientación. Por tanto, la aplicación puede aprovechar estos sensores para funciones 
relacionadas con el senderismo, como registrar el movimiento y la orientación del usuario
- El dispositivo dispone específicamente de un detector y un contador de pasos, además de un 
acelerómetro y otros sensores de movimiento. Por tanto, la aplicación puede utilizar estos sensores
para registrar los pasos realizados durante una ruta y mostrar al usuario información sobre su 
actividad, como el número de pasos realizados durante la excursión
